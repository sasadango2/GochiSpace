# 🍽️ GochiSpace

美味しい発見をシェアする、飲食店レビュー共有サービス

## 📝 概要

GochiSpaceは、家族や友人、知人など互いに知り合い同士の関係のみでユーザーがレストランのレビューを投稿・共有できるサービスである。

## 背景と目的
私は、飲食店を選ぶときによく某マップの口コミをよく閲覧するのだが、そこで多くのレビューを見ることができるのは便利だが、個人の主観も入っていて、それって本当に信頼できるレビューなのかと疑問に思うことが多い。「味がイマイチ」「これまでで一番美味しい」など相手のことを何も知らないのに本当にそれらのレビューが自分の飲食店選定に参考になるのだろうか。もし、自分の友人や家族など関係の近い人の飲食店のレビューが閲覧できたらどうだろうか。相手を認知している状態かつ相手の好きな食べ物の好みを把握できたらそのレビューを信頼することができ、飲食店選びの不安がなくなるのではないだろうか。味の好みや店の雰囲気など感じることは人それぞれだが少なからずとも匿名性が高い、サクラレビューに比べたらいいだろう。
現代の飲食店選びにおいて、インターネット上に蓄積された口コミ情報は消費者の意思決定を左右する極めて重要な判断材料となっており、実際におよそ7割ものユーザーがこれらの情報を参考に店舗を選定している。しかしながら、既存の主要なレビューサイトの多くは匿名性が高く、誰が発信した情報なのかが不明瞭である。そのため、情報の透明性や信頼性が欠如しており、サクラによる書き込みや嗜好の不一致など、ユーザーにとって最適な店舗選びを阻害するノイズが混在しているのが現状である。多くのプラットフォームでは投稿内容の真偽を担保する仕組みが十分ではなく、店舗の実態と乖離した評価や、個人の主観に過度に偏った情報で溢れている。一方、消費者意識調査の結果に目を向けると、情報の信頼元として「家族、友人、知人」を重視する割合が最も高く、顔の見えない第三者による口コミサイトの情報よりも、身近で信頼できる人物からの意見が圧倒的に重視されていることがわかる。このことから、既存サービスでは情報の利便性向上と信頼性の確保が両立できていない点が大きな課題であり、信頼できる人同士の繋がりでの効率的な情報共有の仕組みが強く求められていると言える。そこで本開発は、不特定多数に向けた発信ではなく、家族や友人など関係性の近い人同士のみで飲食店レビューを共有できるWebサービス「GochiSpace」を開発し、情報の信頼性を完全に確保した状態で安心して飲食店選定ができる新たな体験を提供することを目的とした。


### 主な機能

- 🔐 **ユーザー認証** - Firebase Authenticationによる安全なログイン
- **相互フォロー機能**：友人同士でのみレビューを共有するクローズドな設計
- **マップ表示機能**：地図上のマーカーからレビューを閲覧
- **嗜好設定**：好きなジャンル最大3つを登録し、プロフィールで共有
- **フォローユーザー検索機能**：ユーザー検索をし、フォロー申請を送信
- **レビュー投稿機能**:店舗を検索しその結果から該当店舗を選択し登録、カテゴリー選択、評価、コメントを入力し投稿


## 🚀 技術スタック

### フロントエンド
- **React 19** - UIライブラリ
- **React Router v7** - ルーティング
- **Material-UI (MUI) v7** - UIコンポーネント
- **@emotion** - CSS-in-JS

### バックエンド・インフラ
- **Firebase v11** 
  - Authentication - ユーザー認証
  - Firestore - NoSQLデータベース
  - Hosting - 静的ホスティング
- **Google Maps JavaScript API** - 地図機能
> [!WARNING]　
> 本サービスは完全無料枠での開発を行なったため、ユーザー数が増えるとマップ表示や飲食店検索、レビュー投稿に制限がかかる可能性がある。
